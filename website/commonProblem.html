After the ag-graph container height changes and nothing else in my code has changed, why do node positions shift?
We use a Cartesian coordinate system with the center of the container as the origin (0, 0). When the container height changes, node positions shift relative to the origin. This is expected behavior and makes screen adaptation easier.
Does ag-graph control the container height? My plain div container is small and doesn't have a default height: 100%.
Yes, you need to specify width and height yourself. That flexibility is intentional — ag-graph supports CSS for sizing, so all common units work (px, vh, %, em, rem, calc, etc.). 

  /* For reference only */
  #ag-graph-container {
    width: 100%;
    min-width: 20vh;
    max-width: 1920px;
    height: calc(100% - 20px);
    min-height: 20em;
    max-height: 50rem;
  }
I followed the official API docs and added nodes and links, but nothing can be moved or edited. Do I need additional configuration? Why isn't interaction enabled by default?
You need to enable edit mode before you can drag nodes, edit links, and similar operations. When edit mode is off, you can add path animation trajectories. 

  // Initialize
  var agGraph = new AgGraph({container: "#ag-graph-container"});
  // Toggle edit mode
  agGraph.startEdit();
By default, most use cases are view-only. Editing is mainly needed during initial setup, and changes are infrequent afterward. Access control is also a factor — not everyone should have edit permissions.
