Selection Events Selection events are changes to node, line, or point selection state in the graph
Instructions

1. Click any unselected node to select it (deselects other nodes)

2. Shift+click any unselected node to add it to selection

3. Click any unselected line to select it (deselects other lines)

4. Shift+click any unselected line to add it to selection

5. Click empty space to clear all node and line selections
