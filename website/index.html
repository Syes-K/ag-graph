Quick Start 

  // Initialize
  var agGraph = new AgGraph({container: "#graph-container"});
  // Add node
  var node1 = agGraph.addNode({
    id: "n1",
    x: -125,
    y: -66,
    size: 40,
    image: "./assets/img/example/server.svg",
    badge: "H"
  });
  var node2 = agGraph.addNode({
    id: "n2",
    x: 86,
    y: 53,
    size: 40,
    image: "./assets/img/example/pc.svg",
    text: "PC"
  });
  // Add link
  var line = agGraph.addLine({
    id: "edge1",
    source: 'n1',
    target: 'n2',
    "text": "Link",
    animate: true,
    "pointsData": [
      {x: -125, y: -38},
      {x: -72, y: 36},
      {x: 11, y: -20},
      {x: 61, y: 49}
    ]
  });
  // Add motion path
  agGraph.addPath({
    id: "p1",
    source: "n2",
    target: "n1",
    repeat: true
  });
What is ag-graph?
ag-graph is a professional graphical interface development toolkit. With the rapid growth of big data and artificial intelligence, data visualization has taken center stage. ag-graph was built for this moment.
Why do you need ag-graph?
Have you ever needed to visualize data and struggled to find the right tool?
Or found one that couldn't be deeply customized? Or been frustrated by rough, unpolished UI?
Or submitted issues and heard nothing back?
ag-graph: "None of that is a problem."
