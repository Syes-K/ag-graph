Quick Start 

  // Initialize
  var agGraph = new AgGraph({container: "#graph-container"});
  // Add node
  var node1 = agGraph.addNode({
    id: "n1",
    x: -125,
    y: -66,
    size: 40,
    image: "./assets/img/example/server.svg",
    badge: "H"
  });
  var node2 = agGraph.addNode({
    id: "n2",
    x: 86,
    y: 53,
    size: 40,
    image: "./assets/img/example/pc.svg",
    text: "PC"
  });
  // Add link
  var line = agGraph.addLine({
    id: "edge1",
    source: 'n1',
    target: 'n2',
    "text": "Link",
    animate: true,
    "pointsData": [
      {x: -125, y: -38},
      {x: -72, y: 36},
      {x: 11, y: -20},
      {x: 61, y: 49}
    ]
  });
  // Add motion path
  agGraph.addPath({
    id: "p1",
    source: "n2",
    target: "n1",
    repeat: true
  });
What is ag-graph?
An SVG-powered graph visualization toolkit for the web.
Build interactive node-link diagrams, network topologies, and custom data views — with a simple API and full control over every detail.
Why ag-graph?
Most tools make you choose: easy to use, or truly customizable.
Hard to find one that looks great out of the box. Harder still to get help when you're stuck.
ag-graph is built for teams who refuse that tradeoff.
Why teams choose ag-graph
  • Enterprise licensing with custom support
  • Stable API — easy to adopt, built to scale
  • Full CSS control over every SVG element
  • Right-click to inspect and debug in place
